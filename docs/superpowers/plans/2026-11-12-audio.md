# SHIFT Audio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Loop both supplied tracks with quiet licensed UI/chat effects.
**Architecture:** Persistent browser audio controller, one media source for music, decoded one-shot effects through gain nodes. No backend gameplay changes.
**Tech Stack:** Existing vanilla JS, Web Audio and Node tests/Playwright.
**Spec:** docs/superpowers/specs/2026-11-12-audio-design.md

## Global Constraints
- Cloud only; preserve current main/Arthur's updates.
- No autoplay before explicit gesture, no external audio requests during play.
- No private case/session data in assets or tests.

## Review Focus
- Repeated polls and remounts must not replay historical messages.
- Autoplay/media failures must not break gameplay or create unhandled rejections.
- Background tabs must stop sound; mute must apply immediately.
- 320px screen/keyboard and dialog focus must stay usable.
- Stored settings must be bounded and survive unavailable storage.
